# 动画导演规范

动画不是"把文字动起来"，是**用运动表达关系**。每 1 秒运动都必须能回答："这一下改变了学生的什么理解？"

## 1. 画布与版式

```
1280 × 720（16:9），viewBox 固定，等比缩放
┌──────────────────────────────────────────────┐
│ 学科徽标            [镜头 03/09]              │ y 28–92
│ 镜头标题（34px）                              │
│ ──────────────────────────────────────────── │ y 126
│                                              │
│   内容安全区  x 64–1216, y 150–592            │
│   （图形、公式、标注；不放长句）               │
│                                              │
│ ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁ │ y 600
│ 字幕（24px，最多 2 行，左对齐）                │
│ 进度 / 时间 / 快捷键提示                       │ y 690–720
└──────────────────────────────────────────────┘
```

- 内容区与字幕区**物理隔离**，从设计上杜绝"字幕压图"。
- 两栏布局：左 64–620，右 660–1216，中缝 40px。三栏不超过。
- 单屏文字块 ≤ 3；总字数 ≤ 60（不含字幕）。

## 2. 视觉层级

按重要性分配"对比度预算"，一屏只有一个主角：

| 层级 | 用法 | 实现 |
|---|---|---|
| L1 主角 | 本镜头的关键对象（一条曲线、一个光路、一组粒子） | 主色、线宽 3–4px、满不透明度 |
| L2 支撑 | 坐标轴、辅助线、容器 | 中性灰 `#c9d4e2`，1.5px |
| L3 上下文 | 网格、已讲过的旧内容 | 浅灰 `#e3eaf3`，1px，60% 透明 |
| L4 注释 | 标注、单位、数值 | 17px，深灰 `#5b6b80` |

**同一时刻只允许一个 L1。** 需要并列对比时，用左右分区 + 统一线宽，靠位置而不是颜色区分主次。

## 3. 运动词汇表

| 认知动作 | 动效 | 参数 | 备注 |
|---|---|---|---|
| 引入 | 淡入 + 上浮 14px | 0.5s `easeOut` | 不要从屏幕外飞入，除非有空间隐喻 |
| 强调 | 放大 1.06 倍 + 描边加粗 | 0.4s 往返 | 不改变布局位置 |
| 推导 | 逐行出现（上一行上移让位） | 每行 0.45s，间隔 0.35s | 保留已出现的行 |
| 生成图像 | 路径描边生长 | 1.2–2.5s，按长度定 | 先画坐标轴再画曲线 |
| 数值变化 | 数字滚动 / 条形增长 | 与解说同步 | 必须可停在中间态被截图检查 |
| 因果 | 箭头生长 → 目标高亮 | 箭头 0.6s，目标延迟 0.2s | 箭头指向要准确到边 |
| 对比 | 同位置切换 / 左右平移对齐 | 0.6s | 保持共同参照物不动 |
| 分解/组合 | 沿直线分离/汇聚 | 0.8s | 化学反应用此表达粒子重组 |
| 转场 | 场景整体淡入 0.4s | 仅此一种 | 禁止翻页、旋转、缩放转场 |

节奏基准：

- 元素入场 0.4–0.6s；退场 0.3s。
- 关键结论出现后**静止 ≥ 1.5s**，字幕要被读完。
- 同一镜头内不要有 > 3 个同时运动的元素（认知过载）。
- 镜头平均时长 15–25s；< 8s 的镜头通常是凑数，合并或删除。

## 4. 镜头调度

默认**固定机位**。需要"镜头感"时按优先级选：

1. **局部强调**：其余元素降到 40% 透明，主角保持 100%，加一圈浅色背景块。
2. **取景框**：画一个圆角矩形框住局部，框外内容变淡（不真的缩放）。
3. **推近**：整体 `transform: scale(1.15)` 并平移，必须留出安全边距，禁止把标注推出画面。
4. **分屏**：左右各 560px，中间 40px 分隔线，用于对比。

禁止：无意义的缓慢漂移、呼吸缩放、全程镜头晃动。

## 5. 颜色

| 用途 | 值 |
|---|---|
| 背景 | `#f6f8fb` |
| 面板 | `#ffffff` |
| 主文字 | `#16202e` |
| 次文字 | `#5b6b80` |
| 辅助线 | `#c9d4e2` |
| 网格 | `#e3eaf3` |
| 学科主色 | 数学 `#2f6fed` / 物理 `#e8590c` / 化学 `#0f9d58` / 生物 `#7b3fe4` |
| 正确/强调 | 同主色 |
| 错误/警示 | `#d94a3d`（仅用于纠错，不用于普通强调） |

规则：

- **不能只靠颜色区分**。同时给文字标签、形状差异或位置差异。
- 同一画面颜色 ≤ 4 种（不含灰阶）。
- 文字与背景对比度 ≥ 4.5:1；彩色文字一律用深色版本，不用纯饱和色写正文。

## 6. 字幕

- 24px，行高 1.4，左对齐，最多 2 行，单行 ≤ 34 汉字。
- 换句时淡入 0.2s，不做打字机效果（打字机拖慢阅读）。
- 字幕不与旁白重复（本项目默认无旁白）。
- 数字与单位之间留空格；公式中的变量用斜体。

## 7. 镜头衔接

三种合法衔接：

1. **承接**：上一镜的结论成为下一镜的起点（画面元素保留或同位替换）。
2. **设问**：上一镜结尾抛问题，下一镜开头给现象。
3. **放大**：从整体图切到局部细节（用取景框，不用缩放转场）。

禁止：无过渡的硬切到完全无关画面；同一镜头内反复切回上一镜内容。

## 8. 反模式清单（评审必查）

- [ ] 每屏都有大段文字，像 PPT。
- [ ] 元素入场后**再也没动过**，直到下场消失。
- [ ] 动效与知识点无关（飘动的云、旋转的星星、闪烁的边框）。
- [ ] 同一时刻 4 个以上元素在动。
- [ ] 字幕换得比读得快（< 2s 一句）。
- [ ] 关键结论一闪而过，没有静止停留。
- [ ] 用颜色作为唯一区分手段。
- [ ] 镜头 < 8s 且没有独立认知功能。
