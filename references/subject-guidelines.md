# 学科规则与知识自检

每个学科都有"画错一点都不行"的硬约束。本文件是交付前的逐条对照清单。

## 通用

- 术语用教材说法（人教版为主），不混用大学术语。
- 公式中的每个符号在首次出现时给中文名与单位。
- 示意图必须标注"示意图"（仅当涉及不可见尺度/简化模型时）。
- 数值例子必须**当场可验算**，不能出现自相矛盾的数字。

---

## 数学

### 硬约束

1. **坐标映射统一**：所有点、曲线、标注必须走同一套 `x(v)/y(v)` 映射，禁止手写屏幕坐标。
2. **图像与解析式一致**：画完曲线后至少用 3 个点回代验证（顶点、与轴交点、任一点）。
3. **比例尺声明**：x 轴与 y 轴单位长度不同时，必须标注"两轴单位长度不同"，否则学生会误判斜率/开口。
4. **曲线平滑**：用 200+ 采样点折线，不用两点直线代替曲线。
5. **符号规范**：`y=ax²+bx+c (a≠0)`，条件不能漏；自变量范围要写。
6. **几何图**：直角标记、等长刻度（单/双短划）、等角弧线必须画；不能只靠颜色。

### 常见知识错误（人工必查）

- 二次函数顶点公式写成 `(-b/2a, (4ac-b²)/4a)` 却把 `4a` 写成 `2a`。
- 说"a 越大开口越大"（应为 |a| 越大开口越小）。
- 勾股定理中把任意边当斜边。
- 全等判定写成 "SSA" 或 "AAA"。
- 函数图像只画第一象限，却声称"整个图像"。

### 视觉惯例

- 坐标系：x 轴向右箭头，y 轴向上箭头，原点标 `O`。
- 函数曲线主色，辅助线（对称轴、渐近线）用虚线 + 标注。
- 关键点用实心圆点 + 坐标标签，标签避让曲线（偏移方向随位置）。

## 物理

### 硬约束

1. **方向必须对**：光线箭头由光源指向传播方向；力的箭头由受力物体指向施力方向；电流箭头由正极经外电路到负极。
2. **角度定义必须画**：入射角/折射角是**与法线**的夹角，不是与界面。必须画法线（虚线）与角弧。
3. **矢量三要素**：大小、方向、作用点；受力分析要画在受力物体上，不画在施力物体上。
4. **运动学一致性**：匀速=等间距；加速=间距递增；不能匀速运动配"加速"字幕。
5. **不引入未讲过的力**：如斜面小车未说明摩擦时，不要画摩擦力箭头。
6. **单位与量级合理**：中学生例题用常见量级（速度几 m/s，电压 3–220V）。

### 常见知识错误（人工必查）

- 折射：光从空气入水，折射角**小于**入射角（不是大于）；从水入空气则相反。
- 牛顿第一定律：说"物体不受力时一定静止"（漏掉匀速直线运动）。
- 惯性：说"受到惯性作用""惯性力"。
- 浮力：说"浮力随深度增大"（浸没后不变）；说"重的物体一定下沉"。
- 串并联：串联电流处处相等、电压按电阻分配；并联电压相等、电流按电阻反比分配，两者不能混。
- 电路：短路画成用电器被导线并联而未标注。

### 视觉惯例

- 光线：黄色/橙色细线 + 箭头，法线用灰色虚线，角弧用细弧 + 角度标签。
- 力：红色箭头，标注 `F`、`G`、`f`；重力竖直向下。
- 电路：电池长线正极、短线负极；导线横平竖直，直角转折。
- 运动：用"频闪照片"式等时间间隔残影表达速度变化。

## 化学

### 硬约束

1. **原子守恒**：反应前后每种元素的原子个数必须相等；配平错误是硬失败。
2. **粒子图例**：不同元素用不同颜色 + 不同大小/图案，并在角落给图例；不能只靠颜色。
3. **微观图≠真实比例**：必须标注"示意图，未按真实比例"。
4. **条件标注**：点燃、加热、催化剂、通电写在反应条件位置（箭头上/下方）。
5. **状态符号**：气体 ↑、沉淀 ↓ 在方程式中正确使用（初中阶段按教材要求）。
6. **质量守恒的边界**：强调"密闭容器/参加反应的全部物质"，开放体系质量变化不等于定律失效。

### 常见知识错误（人工必查）

- 配平：`H₂ + O₂ → H₂O` 未配平（应为 `2H₂+O₂→2H₂O`）。
- 质量守恒：把"蜡烛燃烧后变轻"解释为"物质消失"（应为生成气体逸散）。
- 原子结构：核电荷数=质子数=核外电子数（原子态），离子态电子数不同。
- 把"原子不可分"当成现代观点（化学变化中原子不可分，但原子有内部结构）。
- 燃烧条件三条（可燃物、氧气/空气、达到着火点）漏项。

### 视觉惯例

- 反应物在左、生成物在右，箭头居中，条件在上方。
- 粒子用小圆（原子）+ 组合（分子），反应过程用"拆开—重组"动画。
- 配平前后用"原子计数表"同步显示数字变化，这是动画的独特价值。

## 生物

### 硬约束

1. **结构与功能对应**：每讲一个结构必须讲它"为什么长这样/有什么用"。
2. **不目的论**：不说"植物为了…所以…"，改为"…使得…"。
3. **层次清楚**：细胞 → 组织 → 器官 → 系统 → 个体，不跳级。
4. **对照实验要素**：单一变量、对照组、重复；缺一项要说明。
5. **示意图标注**：细胞器大小比例不必真实，但相对位置和数量关系要合理（如叶绿体只在植物绿色部分）。

### 常见知识错误（人工必查）

- 光合作用：把"原料"写成"氧气和水"；把"场所"说成"叶绿体基质"以外的错误位置（初中：叶绿体）。
- 光合作用与呼吸作用混淆：光合作用储能量、呼吸作用释放能量，两者不是"白天/晚上"的简单对立。
- 细胞壁：说"细胞壁控制物质进出"（应为细胞膜）。
- 食物链：箭头方向写成"被捕食者←捕食者"（应为能量流动方向：被捕食者→捕食者）。
- 基因型书写：一对基因中显性基因写在前（Dd，不写 dD），这是约定，不是等价写法。
- 分离定律：F₁ 全为显性性状不等于隐性基因消失；解释必须落到"配子形成时成对基因分离"。
- 把动物细胞说成"没有液泡"（有小液泡，只是不如植物明显——按教材表述处理）。

### 视觉惯例

- 细胞：细胞膜单线、细胞壁双线（植物）、细胞核深色圆、叶绿体绿色椭圆、液泡大而透明。
- 生理过程：用"输入→场所→输出"的三段式布局，箭头表示物质流向。
- 生态系统：能量金字塔/箭头链，标注"能量递减"。

## 跨学科通用自检（交付前必做）

1. 把动画静音看完一遍（只有画面和字幕），能否复述结论？
2. 暂停在任意关键帧，画面是否自洽（没有半截公式、错位标注）？
3. 所有数字是否能在 10 秒内手算验证？
4. 是否存在"看起来对但表述错"的句子（如"a 越大开口越大"）？
5. 撤销所有颜色，仅靠形状与文字，信息是否仍然完整？
