# 教学设计规范

本文件回答一个问题：**这个知识点，怎样讲学生才真的懂？**

## 1. 先定位，再设计

### 1.1 学段决定抽象层级

| 学段 | 认知特点 | 设计约束 |
|---|---|---|
| 六–七年级 | 具体运算为主，依赖直观 | 先现象后概念；每屏一个变量；避免多步符号推导；用生活类比但要标注类比的边界 |
| 八–九年级 | 形式运算起步，能接受公式 | 允许"现象→归纳→公式"三段式；公式必须配图像或数值验证；引入反例 |
| 高中 | 抽象建模能力较强 | 可做多参数联动、极限过程、微观模型；但仍需一个具体锚点 |

### 1.2 先备知识必须显式

不要假设学生"应该会"。写出 2–4 条先备知识，并在动画里用 1 个镜头快速激活（不是重新教）：

- 二次函数 → 需要"坐标平面描点""完全平方公式"。
- 光的折射 → 需要"光沿直线传播""法线与角度的定义"。
- 质量守恒 → 需要"物质由粒子构成""化学变化的本质是新物质生成"。

缺先备知识时，用一句话 + 一个画面唤醒，不展开。

## 2. 找难点：三类误解

| 类型 | 例子 | 处理策略 |
|---|---|---|
| 直觉误导 | "力是维持运动的原因"；"重的物体下沉得快" | 先让学生预测 → 动画给出反例 → 再解释 |
| 符号/表述混淆 | "b 决定抛物线左右"；"惯性是一种力" | 用对照实验式画面，同时呈现正确与错误，错误项打叉并给理由 |
| 尺度/模型误解 | 把原子示意图当真实比例；把光路图当实际光线粗细 | 画面角落常驻"示意图，非真实比例"标注；讲清模型与实物的差别 |

写作模板（写入 `analysis.misconceptions`）：

```
误解：<学生的错误说法>
表现：<会在哪道题/哪个现象上出错>
根因：<缺失哪个概念，或被哪个日常经验误导>
纠正：<用哪个镜头、哪个反例、哪句话纠正>
```

## 3. 核心点筛选

一个 2–3 分钟的动画，**最多承载 3–6 个核心点**。判断标准：

1. 它是后续学习的必要条件吗？
2. 去掉它，学生会不会做错题？
3. 它是否必须"看见变化"才能理解？

三条都不满足 → 放进 `optionalPoints`，不讲。

反面例子（二次函数）：把"判别式、根与系数关系、对称性、最值、开口、平移、实际应用"全塞进 2 分钟 → 每个都讲不透。正确做法：本集只讲"开口方向 + 对称轴 + 顶点"这条主线。

## 4. 叙事结构

### 4.1 七步骨架

| 步 | 作用 | 典型时长 | 画面特征 |
|---|---|---|---|
| 提出问题 | 制造认知缺口 | 10–15s | 一个现象/一个矛盾/一个待解问题 |
| 建立直觉 | 用熟悉经验锚定 | 15–25s | 具体例子、可视化类比 |
| 展示过程 | 让变化被看见 | 20–40s | 连续变化、逐帧推进 |
| 解释原理 | 从现象抽到规律 | 20–30s | 关键量标注、因果箭头 |
| 推导结论 | 形成可迁移的结论 | 20–35s | 公式逐行生成、图像验证 |
| 应用验证 | 证明"能用" | 20–30s | 例题/预测/反例检验 |
| 总结重点 | 固化结构 | 10–15s | 3 条以内要点 + 一句易错提醒 |

不是每个知识点都要七步齐全：概念课可省略"推导"，习题课可压缩"直觉"。但**问题、过程、结论、总结**四步必须有。

### 4.2 每镜头只做一件事

一个镜头里同时出现"新概念 + 新公式 + 新图像"= 学生什么都没记住。

判断方法：用一句话写出该镜头的 `objective`，如果这句话有"并且"，就该拆镜头。

## 5. 字幕写作

字幕是唯一的知识载体（默认无配音），标准高于普通课件。

| 规则 | 说明 |
|---|---|
| 一句一个动作 | 每句只推进一个认知步骤 |
| ≤ 34 字 | 超过则拆句或拆镜头 |
| 口语化公式 | "a 大于零，开口向上"而非"a>0 ⇒ 开口向上" |
| 少用代词 | "它""这个"指代不明是理解杀手，重复名词 |
| 给因果，不给结论堆 | "因为光从水进入空气，速度变大，所以折射角大于入射角" |
| 允许停顿 | 关键结论后留 1–2 秒空镜，让字幕被读完 |

字幕与画面分工：

- 画面负责**是什么**（形状、位置、数量、变化）。
- 字幕负责**为什么**（原因、条件、推理、易错点）。

## 6. 时长估算表

| 内容形态 | 参考时长 |
|---|---|
| 单一概念 + 一个例子 | 75–100s |
| 概念 + 图像/实验 + 一个例题 | 110–150s |
| 公式推导 + 图像验证 + 应用 | 150–200s |
| 多情况对比（串并联、三种判定） | 180–240s |
| 微观过程 + 宏观现象 + 化学方程式 | 160–220s |

经验值：**观众阅读一行 24px 字幕约需 2.5–3 秒**。一个镜头若字幕有 4 句，至少 12 秒。

## 7. 自检清单

交付前逐条回答：

- [ ] 学段与抽象层级匹配吗？
- [ ] 先备知识是否被激活（而非默认具备）？
- [ ] 最容易被误解的点，是否被"预测→反例→解释"处理？
- [ ] 核心点是否 ≤ 6 个？拓展内容是否被砍掉？
- [ ] 每个镜头的 objective 是否只有一件事？
- [ ] 每条字幕是否 ≤ 34 字、是否给因果而非堆结论？
- [ ] 结论是否在图像/数值上被验证过？
- [ ] 总结是否只保留 3 条以内、且包含一句易错提醒？
