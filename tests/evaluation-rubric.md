# 人工评审表

自动检查只回答"能不能放、有没有越界、数值对不对"。本表回答"讲得好不好"。

## 使用方式

1. 先跑 `python scripts/run_tests.py --set <set>`，得到自动分与截图目录 `outputs/frames/<case>/`。
2. 打开 `lesson.html`，从 0 连续播放一遍（不看代码）。
3. 再按镜头暂停，对照截图逐项打分。
4. 每条扣分必须写"镜头 id + 时间 + 看到了什么"。

## 专项检查

### 教学

- [ ] 引入是否提出一个真问题（不是"我们今天来学习……"）？
- [ ] 是否先给直觉再给符号？
- [ ] 误解是否被显式说出、并用反例处理？
- [ ] 结论是否在图像/数值上被验证？
- [ ] 总结是否 ≤3 条，且含一句易错提醒？

### 动画

- [ ] 每个镜头至少有一个元素发生"状态改变"（不只是淡入）？
- [ ] 同一时刻运动元素 ≤3？
- [ ] 关键结论后有 ≥1.5s 静止？
- [ ] 是否存在与知识无关的装饰运动？
- [ ] 镜头 <8s 的是否有独立认知功能？

### 知识

- [ ] 公式/数值可当场验算？
- [ ] 方向（光线、力、电流）正确？
- [ ] 粒子数量/配平正确？
- [ ] 示意图是否标注了"非真实比例"（涉及微观/宇宙尺度时）？
- [ ] 是否只靠颜色区分对象？

## 评审分工建议

- 开发 Agent 自评一次（本仓库记录的就是自评）。
- 如条件允许，由另一个模型/人独立评审：只给 `lesson.html` + 本表，不给分镜与源码，减少"自我确认"偏差。
- 关键知识正确性以教材/权威资料为准，不以模型一致意见为准。
