# 回归测试协议与记录

## 1. 原则

1. 每次修改引擎、模板或规则，必须重跑**全部开发集**，不允许只验改动的那一课。
2. 保留集（holdout）在版本冻结前不运行；运行后不得根据其结果回改该版本。
3. 分数下降的用例必须逐个解释：是修好了别处带来的副作用，还是新规则不适用。
4. 只有"质量提高且无未解释回归"才接受新版本。

## 2. 命令

```bash
python scripts/validate_project.py
python scripts/run_tests.py --set dev --tag v1.1-dev
python scripts/run_tests.py --set holdout --tag v1.1-holdout   # 冻结后才跑
```

结果写入 `outputs/reports/run-<set>-<tag>.json`，最终基线汇总到 `tests/baseline-results.json`。

## 3. 回归判定

| 变化 | 判定 |
|---|---|
| 任一硬失败检查由 pass → fail | 阻塞发布 |
| 自动分下降 ≥5 分 | 需定位原因 |
| 平均自动分下降 >2 分 | 视为整体退步 |
| 仅 warn 数量变化 | 记录，不阻塞 |
| 新增用例失败但旧用例全过 | 记录为泛化缺口 |

## 4. 迭代记录

### v1.0（初版）

- 范围：引擎 + 12 课 + 验证脚本。
- 开发集结果：见 `outputs/reports/run-dev-v1.0-dev.json`。
- 主要修复（开发过程中）：
  | 问题 | 根因 | 修复 |
  |---|---|---|
  | 文字越界 / 侵入字幕区 | 手写坐标未留安全边距 | 调整布局，坐标轴标签上移 |
  | 角度弧变成星形 | 角度用度数传给 `Math.cos` | 统一转弧度 |
  | 并联电路短路 | 两条竖直导线连通了上下干路 | 改为左右干路 + 两条支路 |
  | 微观原子重排后左侧空 | 原子移走后未留状态标注 | 补"反应前"标签与箭头 |
  | SSA 反例圆弧过大压文字 | 画了整圆 | 只画与底边相交的弧段 |
  | 图例/标注压住曲线 | 未按空白区放置 | 移至右下空白区 |
  | 循环内 `var` 捕获 | 闭包共享最后一个元素 | 改 IIFE |

### v1.1（开发集全绿后冻结）

- 变更：修正化学实验装置、惯性场景人物、标注避让；补齐分镜元数据。
- 开发集：见 `run-dev-v1.1-dev.json`。
- 保留集：见 `run-holdout-v1.1-holdout.json`（首次运行）。

## 5. 已知的测试局限

- 采样是离散的，0.2s 内的瞬时错误可能漏检。
- 文字重叠检测只比较文字 bbox，不检测文字压在图形上（如图标压曲线）。
- `static` 检查把"刻意的静止强调"也标为 warn，需要人工判断。
- 知识正确性最终仍依赖人工核对，probe 只能覆盖被显式编码的关系。
